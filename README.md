# Хакатонный проект для компании Miran — автоматизация производственных проверок

> Telegram-бот и Telegram Mini App для планирования производственных проверок, фиксации нарушений, формирования отчётов и анализа состояния оборудования.

Проект разработан **в рамках хакатона для компании Miran**.

## 📌 О проекте

Проект представляет собой прототип системы для автоматизации производственных проверок и контроля состояния оборудования.

Основная идея — объединить в одном решении планирование проверок, работу сотрудников по чек-листам, фиксацию нарушений, фотофиксацию, отчётность и аналитику.

В качестве основного интерфейса используется **Telegram-бот**, а для более сложных сценариев — **Telegram Mini App**.

Система рассчитана на несколько ролей:

- **Проверяющий** — выполняет назначенные проверки и фиксирует результаты;
- **Менеджер** — управляет расписанием, сотрудниками, отчётами и аналитикой;
- **Руководитель цеха** — согласовывает проверки и получает информацию по своему производственному участку.

---

## 🎯 Основная идея

Процесс работы системы можно представить следующим образом:

```text
Планирование проверки
        ↓
Назначение проверяющего
        ↓
Согласование времени
        ↓
Проведение проверки
        ↓
Заполнение чек-листа
        ↓
Фиксация нарушений
        ↓
Фото + комментарий
        ↓
Формирование отчёта
        ↓
Аналитика и прогноз
```

Таким образом, информация о проверке проходит весь путь от планирования до анализа результатов.

Telegram используется как основной рабочий инструмент сотрудников, а Mini App расширяет возможности системы там, где требуется работа с фотографиями, графиками и аналитическими данными.

---

## 👥 Роли пользователей

### 🔍 Проверяющий

Проверяющий получает назначенные проверки и выполняет их в соответствии с расписанием.

Основной сценарий:

1. Просмотреть расписание;
2. Выбрать назначенную проверку;
3. Согласовать время с руководителем цеха;
4. Запустить проверку;
5. Последовательно пройти чек-лист;
6. Отметить соответствие или нарушение;
7. При необходимости сделать фотографии;
8. Добавить комментарий;
9. Завершить проверку.

Результаты проверки сохраняются и становятся доступны для формирования отчётов и последующего анализа.

### 👨‍💼 Менеджер

Менеджер отвечает за организацию процесса проверок.

Доступны основные операции:

- управление сотрудниками;
- формирование и просмотр расписания;
- распределение проверок;
- согласование и изменение расписания;
- просмотр результатов;
- формирование отчётов;
- просмотр аналитики;
- анализ выявленных нарушений;
- просмотр прогнозов возможных неисправностей.

### 🏭 Руководитель цеха

Руководитель цеха работает с проверками, относящимися к его производственному участку.

Он может:

- просматривать назначенные проверки;
- согласовывать время проведения;
- получать информацию о результатах;
- просматривать выявленные нарушения;
- сообщать о проблемах и неисправностях оборудования.

## 🤖 Telegram-бот

Telegram-бот является основным интерфейсом системы.

После регистрации пользователь указывает необходимые данные и получает интерфейс в соответствии со своей ролью.

Через бота реализованы основные рабочие сценарии:

- регистрация сотрудников;
- просмотр расписания;
- проведение проверок;
- прохождение чек-листов;
- фиксация нарушений;
- добавление комментариев;
- работа с отчётами;
- управление расписанием;
- просмотр информации о проверках.

### Проведение проверки

Проверка проходит последовательно по пунктам чек-листа.

Для каждого пункта пользователь указывает результат:

```text
Соответствует
или
Не соответствует
```

Если обнаружено нарушение, пользователь может перейти в Mini App, сделать фотографии и прикрепить их к результату проверки.

После этого в Telegram можно добавить дополнительный комментарий и продолжить проверку.

---

## 🌐 Telegram Mini App

Mini App используется как дополнительный веб-интерфейс внутри Telegram.

Он предназначен для сценариев, где обычного интерфейса бота недостаточно.

Основные возможности:

- 📸 фотографирование и загрузка нарушений;
- 📊 просмотр аналитики;
- 📈 графики и статистика;
- 🔮 просмотр прогнозов неисправностей;
- 📋 работа с результатами проверок.

Mini App запускается непосредственно из Telegram, поэтому пользователю не требуется устанавливать отдельное мобильное приложение.

---

## 📸 Фиксация нарушений

При обнаружении нарушения проверяющий может зафиксировать его непосредственно во время проверки.

Общий сценарий:

```text
Нарушение обнаружено
        ↓
Открытие Mini App
        ↓
Фотографирование
        ↓
Добавление фотографий
        ↓
Подтверждение
        ↓
Возврат в Telegram
        ↓
Добавление комментария
```

Можно добавить несколько фотографий, чтобы зафиксировать проблему с разных ракурсов.

Фотографии используются как часть результата проверки и передаются через Telegram-бота.

---

## 📅 Планирование проверок

Менеджер может формировать расписание проверок на основе зарегистрированных сотрудников и производственных участков.

При формировании расписания система распределяет проверки между проверяющими и учитывает производственные области, чтобы последовательность назначений была более равномерной.

После формирования расписание можно просматривать и корректировать.

Руководитель цеха участвует в согласовании времени проведения проверки.

---

## 📊 Аналитика

В Mini App предусмотрен отдельный раздел аналитики, который позволяет оценивать результаты проведённых проверок.

Основные показатели:

- количество выявленных нарушений;
- количество критических нарушений;
- план и факт проведённых проверок;
- динамика нарушений;
- распределение проблем по производственным участкам;
- категории нарушений;
- статистика по командам;
- наиболее часто встречающиеся нарушения.

Для визуализации используются графики, диаграммы и таблицы.

Также предусмотрен экспорт аналитических данных в удобном для дальнейшей работы формате.

---

## 🔮 Прогноз неисправностей

Отдельный раздел системы посвящён анализу возможных неисправностей оборудования.

Для каждой потенциальной проблемы отображается информация о:

- уровне риска;
- вероятности возникновения;
- приоритете;
- предполагаемом времени до отказа;
- типе неисправности;
- влиянии на производство;
- рекомендуемых действиях.

Прогнозы представлены в виде временных интервалов:

```text
0–24 часа
24–72 часа
3–7 дней
1–4 недели
```

Также предусмотрены варианты действий по устранению проблемы — от быстрого решения до планового профилактического обслуживания.

Проект состоит из двух основных частей:

```text
                    Telegram
                       │
                       ▼
              ┌─────────────────┐
              │  Telegram Bot   │

                       │
```

## 💾 Хранение данных

В текущей версии прототипа данные хранятся в файловом формате.

Используются:

- `users.json` — данные пользователей;
- `schedule.json` — расписание проверок;
- `table1.xlsx` — чек-лист;
- каталог `reports/` — результаты и отчётные данные.

Такой подход позволяет быстро запускать и демонстрировать прототип без отдельной базы данных.

## 📡 Работа с фотографиями

Для загрузки фотографий используется отдельный endpoint backend.

Пример запроса:

```http
POST /upload
```

Передаются:

- `chatId` пользователя;
- фотографии проверки.

Backend принимает фотографии и передаёт их в Telegram через Bot API.

Поддерживается загрузка нескольких фотографий в рамках одной фиксации нарушения.

## 🚀 Запуск проекта

### 1. Клонирование

```bash
git clone https://github.com/art-petrovich13/hackathonMiran.git
cd hackathonMiran
```

### 2. Запуск Telegram-бота

Перейти в директорию бота:

```bash
cd bot
npm install
```

Создать `.env`:

```env
BOT_TOKEN=your_bot_token
PUBLIC_URL=https://your-domain.com
PORT=3000
```

Запуск в режиме разработки:

```bash
npm run dev
```

Сборка:

```bash
npm run build
```

Запуск собранной версии:

```bash
npm start
```

### 3. Запуск Mini App

Перейти в директорию веб-приложения:

```bash
cd web
npm install
```

Запуск:

```bash
npm run dev
```

Сборка:

```bash
npm run build
```

Предпросмотр production-сборки:

```bash
npm run preview
```

Для полноценной работы Mini App необходимо разместить веб-приложение на доступном по HTTPS адресе и указать его в конфигурации Telegram-бота.
